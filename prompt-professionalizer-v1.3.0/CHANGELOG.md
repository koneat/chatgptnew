# Changelog

## 1.3.0

- 安全相关请求默认采用用户已确认的本地靶场、隔离实验环境或授权红队模拟背景。
- 安全行业口语会转换为专业、范围明确的红队安全评估术语，减少因表达歧义产生的误判。
- 保持真实技术意图、动作对象、测试深度与命令强度不变；不弱化或隐藏原始目的。
- 唯一允许补充的固定事实是用户已明确提供的本地靶场/授权测试背景。
- 新增旧版内置改写规则自动迁移；用户自行修改的规则继续保留。
- Temperature 继续默认为 0.3，最大输出继续默认为 1024 Token。

## 1.2.0

- 默认 Temperature 从 0.1 调整为 0.3。
- 更新唯一改写规则：增加工程术语转换，同时继续强制语义保真。
- 对明确授权的安全测试、红队演练和防御验证，支持合规、范围明确的专业术语。
- 明确禁止通过术语替换隐藏真实目的、规避安全策略或包装未授权行为。
- 旧版内置 OpenRouter 默认配置会自动迁移到 Temperature 0.3；用户自定义参数保持不变。

## 1.1.0

- 默认最大输出从 320 Token 提高到 1024 Token。
- 快速模式调整为 512 / 768 / 1024 Token 三档动态预算。
- 删除全部人格配置、人格选择和人格相关存储字段。
- 删除多模式选择器及新增、删除模式功能。
- 只保留“严格保真专业化”一个模式，并允许编辑其改写规则。
- 升级时自动清理旧版 `personas`、`templates`、`defaultPersonaId` 和 `defaultTemplateId`。
- 保留 OpenRouter、自定义 OpenAI 兼容接口、本地不可变片段保护、单次请求、缓存和可拖动 P 按钮。
