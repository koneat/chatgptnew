# Testing

执行：

```bash
node tests/integration.test.js
```

检查范围：

- 默认 OpenRouter 配置、Temperature 0.3 与 1024 Token 上限
- 快速模式 512 / 768 / 1024 Token 动态预算
- 每次点击最多一次外部请求
- 缓存命中不请求模型
- 校验失败不自动重试
- `@`、邮箱、路径和数字原样恢复
- 中文输出检查
- 否定条件保留检查
- 人格和多模式字段不存在
- 系统规则包含固定的本地靶场/授权红队背景
- 系统规则要求保留真实技术意图，禁止凭空增加攻击步骤、目标资产或结论
- v1.0.0、v1.1.0、v1.2.0 内置规则自动迁移到 v1.3.0
- 用户自定义改写规则不被覆盖
- 自定义模型参数与输出上限不被覆盖
